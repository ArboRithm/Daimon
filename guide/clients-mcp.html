Enregistrer Daimon dans vos clients IA ​

Daimon s'enregistre comme serveur MCP nommé daimon dans les clients qu'il détecte sur votre ordinateur. Votre client le lance alors en stdio, avec l'argument serve.

Trois façons de l'enregistrer ​

  1. Le parcours d'installation (panneau › Relancer l'installation…).
  2. Le panneau, avec un interrupteur par client.
  3. Un terminal.

Depuis un terminal ​

macOS :

sh
/Applications/Daimon.app/Contents/MacOS/Daimon status      # ce qui est détecté, ce qui est enregistré
/Applications/Daimon.app/Contents/MacOS/Daimon install     # s'enregistrer dans chaque client détecté
/Applications/Daimon.app/Contents/MacOS/Daimon uninstall   # se retirer

Windows (PowerShell) : redirigez la sortie vers Out-Host pour que l'invite attende la réponse.

powershell
& "$env:LOCALAPPDATA\Daimon\Daimon.exe" status | Out-Host

Après un enregistrement, redémarrez votre client IA.

Clients connus ​

Daimon connaît la configuration de : Claude Code, Claude Desktop, Codex, Gemini CLI, Antigravity, Cursor (éditeur et CLI), Windsurf, VS Code avec Copilot, GitHub Copilot CLI, Zed, JetBrains Junie, Cline, Roo Code, Continue, Amazon Q Developer CLI, opencode, Crush, Mistral Vibe, Qwen Code, Droid, Grok CLI, Goose, LM Studio, 5ire, Witsy, AnythingLLM Desktop, OpenDesign et Trae.

Tous n'ont pas été éprouvés de bout en bout. Si l'un d'eux se comporte mal, ouvrez une issue.

Un autre client MCP ​

Déclarez un serveur stdio dont la commande est :

PlateformeCommandeArgument
macOS/Applications/Daimon.app/Contents/MacOS/Daimonserve
Windows%LOCALAPPDATA%\Daimon\Daimon.exeserve

L'unique argument est serve. Le nom de serveur que Daimon utilise lui-même est daimon.

Vérifier ​

Demandez à votre IA d'appeler daimon_doctor, puis main_ceiling pour connaître le plafond actif.

Confidentialité ​

Tout est local ​

Daimon tourne sur votre ordinateur. Il n'a ni télémétrie ni compte et ne collecte rien. Il n'appelle lui-même aucun modèle d'IA et n'envoie rien à ArboRithm.

Sa seule connexion à Internet est la vérification des mises à jour, servie par GitHub Releases. Si l'outil GitHub CLI (gh) est installé et connecté, cette vérification lui demande aussi, avec votre propre session, si votre compte a accès au canal de mise à jour réservé d'ArboRithm : rien n'est transmis à ArboRithm.

Ce site de documentation ​

Ce site mesure son audience avec Matomo, hébergé par ArboRithm, sans cookie : il compte les pages vues, sans rien déposer chez vous. Cela concerne ce site uniquement ; l'application Daimon, elle, n'envoie rien à ArboRithm.

Ce que fait votre client IA ​

Ce que votre client IA fait de ce qu'il perçoit à travers Daimon (une capture d'écran, le texte d'une fenêtre) se joue entre vous et le fournisseur de ce client. Réglez le plafond et vos exclusions en conséquence.

Les secrets ​

  • Les champs de mot de passe sont masqués dans ce que l'IA lit de l'arbre d'accessibilité.
  • Dans les captures d'écran, ils sont noircis aussi lorsque l'arbre d'accessibilité est lisible (sous macOS, une fois l'autorisation Accessibilité accordée). C'est une passe faite au mieux : le résultat le signale quand elle n'a pas pu avoir lieu.
  • Vos propres exclusions s'ajoutent : applications refusées, zones noircies, titres retirés.

Le journal d'activité ​

Chaque action des Mains est inscrite, sur votre ordinateur, dans un journal dont toute altération se détecte (chaque entrée est chaînée à la précédente). Il consigne ce qui a été fait et sur quoi, jamais le texte saisi. Le bouton Journal d'activité du panneau ouvre son dossier.

Où sont les fichiers ​

Les réglages (exclusions.yaml, update.yaml) sont dans le dossier de configuration, que le panneau ouvre. Le dossier de données par défaut est ~/Library/Application Support/Daimon sous macOS et %APPDATA%\Daimon sous Windows ; la configuration y est dans config et les journaux dans logs.
